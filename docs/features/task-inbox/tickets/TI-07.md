# TI-07: 설정 page(비밀번호·API key·감사), `wb hub tls`, status web 줄

명세: [../SPEC.md](../SPEC.md) s1. 의존성·자원: SPEC "Ticket 그래프"의 TI-07(선행 TI-03). 상태·실제 assignment는 orchestrator 운영 기록에서만 관리한다.
권장 executor: Sonnet(`model: "sonnet"`). 판정 logic은 TI-02 라이브러리에 있고 이 ticket은 page·CLI 연결이다.

## 제공할 동작

- `GET /settings`, `POST /settings/password`(현재 비밀번호 확인 실패 = 로그인 실패와 같은 지연·감사, 성공 = generation+1·현재 세션 재발급·다른 세션 삭제·감사 `password_changed{source:"web"}`).
- `GET/POST /settings/keys`: 목록(이름·등급·scope·마지막 사용·만료·상태, 시스템 key는 "Board agent(시스템)"·폐기 없음), 발급 form(이름·등급·scope 전체/선택 프로젝트·만료), 발급 결과 page(원문 1회, `Cache-Control: no-store`). `GET/POST /settings/keys/<key_id>/revoke` 확인 page.
- `GET /settings/audit`: 최근 순 page(50건), event·시각·주체·주소·detail.
- CLI `wb hub tls --self-signed [--force]`: SPEC "CLI 추가"대로 openssl 호출, 파일 권한(key 0600, dir 0700), 이미 있으면 거절, openssl 없음 exit 2, 지문·재시작 안내. 예약 거절을 대체한다.
- `wb hub status`의 `web:` 줄·평문 경고 줄(`--json`은 hub_v1 그대로). `board_agent:` 줄 자리는 `null`이면 `board_agent: 없음`.
- Hub가 `auth.json` generation 변화를 볼 때 `password_changed{source:"cli"}` 감사를 남기고 세션을 정리한다(TI-02 계약의 Hub 쪽).

## 수락 기준

- P2-AC-17: 웹 비밀번호 변경에 현재 비밀번호 필요, 변경 뒤 다른 브라우저 세션(cookie jar 2개) 무효·현재 유지. CLI 재설정 뒤 모든 세션 무효.
- P2-AC-18: `api_key_issued`·`api_key_revoked`·`password_changed` 감사가 page에 보임, 원문 key·비밀번호 없음.
- P2-AC-19: 발급 page 외 어디에도 원문 없음(목록 HTML·감사·log·DB 확인), 폐기 즉시 MCP 401(TI-05 client로), 목록 필드.
- P2-AC-16: `wb hub tls --self-signed`가 SAN(IP bind, localhost)이 있는 cert·0600 key를 만들고(`openssl x509 -text`), Hub 재시작 뒤 HTTPS. `wb hub status`에 평문 경고 줄(비loopback 판정 주입).

## 계약과 맥락

SPEC "인증·세션·CSRF", "API key", "감사 기록", "CLI 추가". TI-02 라이브러리, TI-03 layout·middleware.

## 검증

Seam T2(page) + T8(CLI, 실제 openssl) + T4(폐기 뒤 401 확인). 독립 기대값: openssl 출력, 파일 mode, 감사 행.

Behavior 순서: 설정 page 접근(세션만) → 비밀번호 변경 실패·지연 → 성공·세션 무효 → key 발급·원문 1회 → 목록 → 폐기 확인 page·즉시 401 → 감사 page → `wb hub tls`(생성·거절·`--force`·openssl 없음) → status 줄 → CLI passwd 뒤 Hub 쪽 감사.

작성 범위: `src/workbench/hub/web/pages/settings.py`, `src/workbench/hub/web/app.py`(route), `src/workbench/hub/cli.py`(tls, status 줄), `src/workbench/hub/server.py`(generation 감시 감사), `tests/hub/test_web_pages_settings.py`, `tests/hub/test_hub_tls_cli.py`.

명령: `python3 tools/shm_tests.py -- env PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m unittest discover -s tests/hub -p 'test_web_pages_settings*.py'`, `… -p 'test_hub_tls_cli*.py'`. 회귀: `… -p 'test_hub_service*.py'`, `-p 'test_hub_web*.py'`.

독립 검증: test_designer가 원문 key 누출(응답 header·redirect URL·감사 detail·Hub log)과 다른 세션 무효화를 확인한다.

## 범위 밖과 중단 조건

인증 판정 logic 변경(TI-02로 되돌림). openssl 외 도구 설치 금지. 실제 사용자 config 경로를 건드리지 않는다(temp XDG_CONFIG_HOME).

## 출력

변경 경로, behavior별 RED/GREEN, 명령·결과, 생성 cert 확인 출력.
