# TI-14: 결과 요약·전체 보기·raw page·산출물 경로 제한

명세: [../SPEC.md](../SPEC.md) s1. 의존성·자원: SPEC "Ticket 그래프"의 TI-14(선행 TI-05, TI-06, TI-11). 상태·실제 assignment는 orchestrator 운영 기록에서만 관리한다.
권장 executor: Opus(`model: "opus"`). Host 파일 노출 범위(D-22 완화의 경계)를 정한다.

## 제공할 동작

- `src/workbench/hub/inbox/results.py`: `summary(request)`(close summary 또는 `task_view` 줄), `full(request)`(ui_v1 `task_status{detail:true}`: run·보고 원문·명령), `raw(request, run_id, offset, length)`(그 요청에 연결된 Task의 run·command source만, ui_v1 `raw_query`), `artifact(request, path, offset, length)`(SPEC 규칙: root 아래 일반 파일, resolve 뒤에도 root 안, `.wb/**`·`.git/**` 제외, ≤ 128 KiB page, 경로는 root 기준 상대 또는 절대 모두 받되 판정은 resolve 결과로).
- MCP `inbox_result{full, run_id, offset, length, artifact_path}` 완성(TI-05 자리).
- 웹 `GET /requests/<rid>/full`, `/raw`, `/artifact`(`text/plain; charset=utf-8`, inline, `X-Content-Type-Options: nosniff`). 상세 page의 결과 요약·"전체 보기" link.
- Backend 꺼짐: 요약과 마지막 `task_view`만, raw·artifact는 `backend_not_running`(artifact는 backend 없이도 읽을 수 있지만 같은 규칙으로 허용 — 아래 결정 참고).

결정: 산출물 파일 읽기는 Hub가 직접 한다(같은 uid, backend 불필요). 그래서 artifact는 backend가 꺼져 있어도 된다. Raw log는 backend의 source 관리(`raw_query`)를 거쳐야 하므로 켜져 있어야 한다.

## 수락 기준

- P2-AC-31: 기본 결과는 요약. `full:true`/웹 전체 보기에서 run·보고 원문·명령 출력 page를 볼 수 있음. requester key가 자기 요청 전체 보기 성공, 남의 요청 `not_found`. 원문 page는 `text/plain`(script 비실행).
- TI-T10: `../`·절대 경로로 root 밖, root 안 symlink → 밖, `.wb/agent.db`류·`.git/config` 요청은 거절. Root 안 일반 파일은 page 단위로 읽힘. 디렉터리·장치 파일 거절.
- P2-AC-13: 다른 프로젝트 Task의 run_id로 raw 요청 거절.
- P2-AC-26(표시): 상세 page에 Task 진행·run 보고 요약.

## 계약과 맥락

SPEC "결과 조회", D-22, ADR-0003 결과(P2-AC-14 완화). ui_v1 `raw_query`·`raw_status`(attach 불필요), TI-09 `task_status`.

## 검증

Seam T6(실제 backend로 run·raw 생성) + T2(웹 page) + T4(MCP). 독립 기대값: 테스트가 만든 파일 bytes·symlink, run log 원문.

Behavior 순서: 요약 → full(보고·명령) → raw page(offset/length·범위 밖 거절) → artifact 정상 → artifact 탈출 5종 거절 → backend 꺼짐 동작 → 권한(requester 자기·남) → 웹 page content-type.

작성 범위: `src/workbench/hub/inbox/results.py`, `src/workbench/hub/mcp.py`, `src/workbench/hub/web/pages/requests.py`, `tests/hub/test_inbox_results.py`.

명령: `python3 tools/shm_tests.py -- env PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m unittest discover -s tests/hub -p 'test_inbox_results*.py'`. 회귀: `… -p 'test_hub_mcp*.py'`, `-p 'test_web_pages*.py'`.

독립 test_designer 검증 필수. 초점: TOCTOU(검사 뒤 symlink 교체 — `O_NOFOLLOW`·fd 기준 재확인), hardlink, 큰 offset, 0 길이, 비UTF-8 파일, `.WB` 대소문자·`/./` 경로.

## 범위 밖과 중단 조건

원문 log 저장 방식 변경, 새 log 보존 정책. Root 밖 파일 공개 확대 금지(필요하면 멈추고 보고).

## 출력

변경 경로, behavior별 RED/GREEN, 경로 판정 규칙 구현 요약, 명령·결과.
