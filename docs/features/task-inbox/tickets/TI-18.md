# TI-18: Board page UI(xterm.js·tab·재연결·banner·재시작)

명세: [../SPEC.md](../SPEC.md) s1. 의존성·자원: SPEC "Ticket 그래프"의 TI-18(선행 TI-17, TI-01). 상태·실제 assignment는 orchestrator 운영 기록에서만 관리한다.
권장 executor: Sonnet(`model: "sonnet"`). 확정된 프로토콜 위의 client UI다.

## 제공할 동작

- `GET /board`: Board agent tab·shell tab(각 xterm.js + fit addon), channel 상태(실행 중/종료/실패·격리 실패 이유), 연결 상태(연결됨/연결 없음/다른 곳에서 연결됨), 재시작 버튼(→ 확인 page `GET /board/restart?channel=` → `POST /board/restart`). CSRF token은 `<meta>`로.
- `static/board-state.js`(순수 상태 기계, DOM 없음, ES module): 상태(`connecting`, `attached`, `disconnected`, `taken_elsewhere`), 재연결 규칙(네트워크 끊김 → 1·2·4…≤15 s backoff로 `resume` hello, `taken_over`/`taken_elsewhere` 뒤 자동 재연결 없음, "다시 가져오기" → `resume:null`), ping 10 s·pong 20 s 없으면 `disconnected`, 입력 frame에 현재 epoch 부착, `pagehide`에서 `release`.
- `static/board.js`: DOM·xterm 연결, banner "다른 곳에서 연결됨 — 다시 가져오기", 연결 없음 표시.
- `/static/vendor/xterm/` 자산만 사용, 외부 URL 없음, inline script 없음.

## 수락 기준

- P2-AC-34: page에 tab 둘, 재시작 버튼(확인 page 거침, 취소 link는 불변).
- P2-AC-35 (5): `board-state.js`가 `taken_elsewhere` 상태에서 banner 상태와 "다시 가져오기" action을 내고, 자동 재연결을 하지 않음(node test). 네트워크 끊김 뒤 resume hello를 backoff로 냄. 인수 뒤 입력이 새 epoch로만 나감.
- P2-AC-37: page HTML·JS에 외부 URL 없음, xterm 자산은 `/static/vendor/xterm/`.
- TI-T02: inline script·`on*=` 없음.

SPEC "WebSocket terminal 프로토콜"(client 규칙), "웹 route와 화면". TI-17 서버, TI-01 자산, TI-16 restart endpoint.
