# 개선 요구사항
아래 내용은 유저의 요구사항으로 현재 개발의 문제점과 그 해결 방안을 원함.

## 1. Web의 디자인이 너무 부실함
- 현재 웹의 디자인이 너무 안좋음 더 잘 정돈되고 표도 잘 표현되고 UI/UX 개선이 필요함
- 로그인 페이지도 개선이 필요함
- 처음 들어가면 dashboard와 같은 느낌을 받을 수 있게 디자인 할 것

## 2. 기능들을 어떻게 들어가야할지 버튼이 없음
- board agent에 들어갈 방법이 없음. 주소/board를 치고 들어가야하는 상황임. board agent에 들어갈 수 있도록 UI/UX가 개선되야 함
- 사용자 설정(api key, 암호 설정 등)을 어디로 들어가야할지 모르겠음.
- 그 외에 있는 기능들을 들어갈 수 있게 해야함.

## 3. 웹 불편사항
- wb에 들어갔다가 뒤로 가기 하면 무조건 'this site doesn't support a secure connectio'이 매번 뜸. 이거 매번은 안뜨게 하고 싶음. 처음에 들어갈 때 뜨는건 이해되지만 뒤로가기 할 때 마다 뜨는건 너무 불편함.
- '평문 HTTP로 LAN에 열려 있습니다. VPN등 네트워크 보호가 필요합니다'가 계속 뜨는데 닫기 버튼이 있어서 닫을 수 있으면 좋겠음.

## 4. 외부 작업 요청
- 작업 요청은 반드시 api key를 통한 보안이 되어야 하며 아무 요청이나 받으면 안됨.
- 외부 agent가 작업을 간단하게 등록 가능해야함. skills 형태로 REST API 형태로 간단하게  특별한 프로그램 없이 외부에서 작업 등록이 가능하면 좋겠지만 어렵다면 github 페이지에서 간단한 코드 파일 1~2개를 통해 skills로 등록 가능하면 좋겠음. 아무튼 이 skills 설치가 간단해야 함. AI agent에게 github 페이지의 skills README.md 링크를 주면 간단하게 설치하고 env 파일을 통해서 api key가 관리되면 좋겠음.
- mcp 접속을 위한 api key를 생성하는 페이지에는 mcp 서버에 등록할 수 있는 정보나 설정 복붙이 가능해야함. 
- API 요청도 web 접속과 동일한 규칙으로 받고 차단이 되어야함. 즉 웹 접속이 가능한 호스트는 등록 가능하고 웹 접속이 불가능한 호스트는 등록 불가능.

## 주의점
- 이 문서를 읽었다면 이 문서를 docs 폴더의 적당한 곳으로 옮겨서 정리할 것.
- 위 불만 사항과 더불어서 필요한 확장 기능은 필요시 구현할 것.
