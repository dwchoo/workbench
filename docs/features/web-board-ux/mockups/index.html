Hub 웹 mockup 비교 (WBX-D14)

Dashboard(/)와 로그인 화면의 정적 mockup 세 방향입니다. 하나를 고르면 그 style.css가 트랙 C(WBX-D12)의 design system 출발점이 됩니다. 모든 화면은 light·dark(prefers-color-scheme, 오른쪽 위 달 버튼은 data-theme 덮어쓰기), 375px 폭, 외부 resource 없음, inline script·style 없음을 지킵니다. 달 버튼과 배너 닫기만 작은 app.js를 쓰고, JS 없이도 화면은 완전합니다.

A. 차분한 관리 콘솔

중립 회색과 파랑 하나. sidebar 없는 상단 nav, 현재 화면은 밑줄. 얇은 선 card와 옅은 색 알약 chip. 가장 기본적인 admin 느낌입니다.

monospace, 항상 어두운 header 막대, 13px 밀도, 표 줄무늬와 [실행 중] 꺾쇠 chip. 상태 코드(NEEDS_INFO)를 그대로 보이고 한 화면에 가장 많은 정보가 들어갑니다.
