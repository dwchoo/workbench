# HB-10: `wb hub enable/disable`, `--version`, 예약 명령

명세: [../SPEC.md](../SPEC.md) s1. 의존성·자원: SPEC "Ticket 그래프"의 HB-10. 상태·실제 assignment는 orchestrator 운영 기록에서만 관리한다.
권장 executor: Sonnet(`model: "sonnet"`). 외부 명령 호출을 감싸는 CLI 작업이다.

## 제공할 동작

`wb hub enable`이 systemd 사용자 unit을 쓰고 enable하며 linger 상태를 알린다. `wb hub disable`이 되돌린다. `wb hub status`에 부팅 자동 시작 상태를 더한다. `wb --version`을 둔다. `wb hub passwd`/`tls`는 예약 거절이다. 이 명령들은 Hub를 자동 시작하지 않는다.

## 수락 기준

- HB-AC-04: 기본 상태(어떤 명령도 `enable`하지 않음)에서 unit 파일이 없다. `enable`은 fake `systemctl`(PATH 앞 script, argv 기록)로 `--user show-environment` → unit 작성 → `--user daemon-reload` → `--user enable omp-workbench-hub.service` 순서로 부른다. unit 내용: `Type=simple`, `ExecStart`가 현재 `sys.executable`·`-I`·`_hub --foreground --mode systemd`(파싱해 원래 argv로 복원 가능), `Restart=on-failure`, `WantedBy=default.target`. `systemctl` 없음·`show-environment` 실패 → exit 2, unit 없음. `enable` 실패 → exit 1, unit 이전 상태로 복원. linger `no` → 안내 문구. `disable` → `--user disable`, unit 삭제, `daemon-reload`, 실행 중 Hub 유지 안내. 이미 꺼짐 → exit 0.
- `wb hub status`: fake `systemctl --user is-enabled` 결과에 따라 enabled/disabled, 실행 불가면 unknown.
- HB-AC-15(나머지): `wb hub enable`·`disable`·`passwd`·`tls`·`wb --version` 뒤 Hub 프로세스 없음.
- HB-T08: `wb --version` exit 0, `wb <release> (<commit 12자>|editable|unknown)` 형식.
- `wb hub passwd`/`tls` → `Web Board 기능에서 제공 예정입니다`, exit 2.
- `_hub --foreground --mode systemd`로 띄운 Hub의 `hub.json` `mode`가 `systemd`이고, lock에서 지면 exit 0.

## 계약과 맥락

SPEC "부팅 자동 시작", "CLI 계약". unit 경로 `$XDG_CONFIG_HOME/systemd/user/omp-workbench-hub.service`. ExecStart 인자 quoting은 systemd 문법(큰따옴표, `\`·`"` escape, `%`→`%%`, `$`→`$$`). 테스트는 실제 `systemctl --user enable`을 실행하지 않는다. version 출처는 `importlib.metadata`(`doctor.installation`과 같은 규칙, 공용 함수로).
